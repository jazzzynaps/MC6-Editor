MC-6 BLE Editor PWA

Bu paket, çalışan BLE-only editörün PWA sürümüdür.
Web Bluetooth ve PWA kurulumu için sayfa HTTPS üzerinden açılmalıdır (veya localhost).
Dosyaları bir HTTPS web sunucusuna aynı klasör yapısıyla yükleyin, index.html'i Chrome Android'de açın ve "Ana ekrana ekle / Uygulamayı yükle" seçeneğini kullanın.
